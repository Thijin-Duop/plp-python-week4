# Week 4 Assignment: Hands-On Lab - Grades, Eligibility & Smart Decisions

This repository contains my Week 4 Python assignment on functions, parameters, return values, and default arguments.

- **welcome.py** — Defines a `welcome()` function that returns a personalized PLP welcome message.
- **toolbox.py** — Defines and tests the `double()`, `is_pass()`, and `greet()` functions.

The hardest function to write was `greet()` because it uses a default parameter while also allowing a different greeting to be provided. I learned how to use a default value so the function works whether or not a greeting is specified.
